## Feedback

Feedback zur Zwischenveröffentlichung des MIO Laborbefundes erfolgt anhand einer Excel-Tabelle. Alle Kommentare werden im Nachhinein anonymisiert veröffentlicht.

Es ist wünschenswert, wenn alle Kommentare aus einer Organisation in einer Excel-Tabelle zusammen gefasst werden, sodass wir pro teilnehmender Organisation eine ausgefüllte Excel-Tabelle erhalten.

Die ausgefüllte Excel-Tabelle kann über die E-Mail Adresse [laborbefund@mio42.de](mailto:laborbefund@mio42.de) bis zum **28.August.2026** eingereicht werden:

[Kommentierungsvorlage_MIO-Laborbefund_1.0.0-update.xlsx](./Feedback_Kommentierungsvorlage_MIO-Laborbefund_100-update.xlsx)

In der Excel-Tabelle können folgende Angaben gemacht werden:

| | | | |
| :--- | :--- | :--- | :--- |
| 1 | **Organisation** | Textfeld | Name Ihrer Organisation über welche Sie den Kommentar einreichen |
| 2 | **Kommentartyp** | Drop-Down-Menü | Einordung, um was für einen Kommentar es sich handelt. Folgende Auswahlmöglichkeiten sind möglich:* **Frage**: Fragen zielen nicht auf eine Änderung der Spezifikation ab, sondern dienen der Klärung von Unklarheiten.
* **Kommentar**: Es handelt sich um Anmerkungen zur Spezifikation, von denen nicht erwartet wird, dass sie zu einer Änderung der Spezifikation führen. Hier darf gerne auch positives Feedback übermittelt werden.
* **Änderungsvorschlag**: Antrag auf eine Änderung innerhalb der Spezifikation, bspw. die Änderung einer Kardinalität oder die Aufnahme eines neuen Elementes in der Spezifikation.
* **Technische Korrektur**: Es handelt sich um kleine Änderungen in der Spezifikation. Das können bspw. Korrekturen in Bezug auf Rechtschreibung/Grammatik oder Diskrepanzen zwischen Informationsmodell und FHIR®-Spezifikation sein. 
 |
| 3 | **IG-Seite** | Drop-Down-Menü | Titel der betreffenden Seite im IG. Diese Angabe ist notwendig, wenn sich Ihr Kommentar auf den textuelle Inhalte des IG bezieht. |
| 4 | **Informationsmodell-Struktur** | Drop-Down-Menü | Auf welchen Inhalt des Informationsmodells bezieht sich der Kommentar, bspw. auf die Diagnose oder die Laboruntersuchung. Diese Angabe ist notwendig, wenn sich Ihr Kommentar auf das Informationsmodell bezieht. |
| 5 | **FHIR®-Profil/Erweiterung** | Drop-Down-Menü | Auf welches FHIR®-Profil bezieht sich der Kommentar. Diese Angabe ist notwendig, wenn sich Ihr Kommentar auf ein FHIR®-Profil oder FHIR®-Element bezieht. |
| 6 | **Terminologie** | Drop-Down-Menü | Auf welches Codesystem oder Valueset bezieht sich der Kommentar. Diese Angabe ist notwendig, wenn sich Ihr Kommentar auf ein Codesystem oder Valuset bezieht. |
| 7 | **Kommentar** | Textfeld | Eine detaillierte Beschreibung Ihrer Anmerkung.Da es in den Dropdown-Menüs der Spalten Informationsmodell-Struktur, FHIR®-Profil und Terminologie nicht möglich ist, das betroffene Element genau anzugeben, ist es um Missverständnisse zu vermeiden notwendig, das Element hier genau zu benennen. Das erleichtert uns im Nachhinein die Zuordnung und Bearbeitung Ihres Kommentars. |
| 8 | **Änderungsvorschlag** | Textfeld | Welche Änderung schlagen Sie vor. |
